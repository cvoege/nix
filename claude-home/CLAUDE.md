# CLAUDE.md

## Rules
- Certain prompts indicate the user is not looking for you to solve the problem. If the prompt says "Diagnose", "Figure out why", "Tell me why" or something similar, answer the question first and offer solution before changing any files.

## Suggestions
- Make liberal use of writing one off scripts for validation. For example, if you are checking that two implementations do the same thing, write a quick script that runs both implementations with a variety of arguments to make sure they return the same thing.
